# ✈️ My Travel Diary

Welcome to my Travel Diary project!

A simple and responsive web application to save, manage and explore your travel memories.

## 🌐 Live Website

[Click Here to Visit My Travel Diary](https://sarthakshelar10.github.io/travel-diary/)

## 🚀 Features

- Add travel memories
- Upload travel photos
- Edit and delete entries
- Search memories
- Filter by categories
- Dark and Light Mode
- Export memories as JSON
- Local Storage support

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- AngularJS
