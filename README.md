✈️ Travel Diary Web Application

A responsive web application to create, organize and explore personal travel memories with photos and trip details.

🌐 Live Demo

[Click here to visit Travel Diary](https://sarthakshelar10.github.io/travel-diary/)

📌 About the Project

Travel Diary helps users save and manage their travel experiences in one place. Users can add destinations, travel dates, descriptions, categories and photographs.

✨ Features

- Add, edit and delete travel memories
- Upload travel photos (up to 2 MB each)
- Search and filter memories by category
- Dark and light themes
- Export saved memories as JSON
- Save entries in browser local storage
- Responsive user interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- AngularJS

🚀 Deployment

Hosted using GitHub Pages.
